Precision Zones

Management-zone delineation for precision agriculture, inside QGIS.

Precision Zones turns one or more rasters over a field boundary into management zones: it resamples and clips the inputs to a common grid, extracts pixel-centroid values, reduces dimensionality with PCA, finds a sensible number of zones with K-Means (Elbow + Silhouette), writes the zones as a raster, optionally smooths them with a majority (mode) filter, and reports per-zone statistics and Variance Reduction (VR%).

Features

  • Resampling & extraction — reproject/clip rasters to the boundary grid (a geographic boundary is auto-reprojected to its UTM zone) and sample values to centroid points.
  • PCA — standardized components with explained/cumulative variance; export CSV reports or PC rasters (single- or multi-band GeoTIFF).
  • Zones — Elbow + Silhouette across a k-range, then generate the management-zone raster from the chosen k.
  • Mode Filter — built-in majority filter on the source grid, preserving zone ids (no SAGA needed).
  • Analysis — per-zone mean, variance, CV%, 95% CI, IQR, skewness, area; area-weighted total VR%; boxplots (PNG).

Use the sidebar (or the Back / Next buttons) to move through the workflow: Resampling → PCA → Zones → Mode Filter → Analysis. Python dependencies install automatically on first run.
