description=Create management zones from rasters using PCA and K-Means with Elbow and Silhouette metrics, plus resampling, variance-reduction analysis, optional zone smoothing (Mode Filter), and rich CSV/PNG exports. PCA table includes Eigenvalue (λ).

about=Features:
  - Resampling & raster value extraction inside a boundary.
  - PCA with explained variance table (incl. Eigenvalue λ) and CSV export.
  - K-Means clustering with Elbow curve and Silhouette score; export indices; generate zones as a raster.
  - Optional zone smoothing (Mode Filter): SAGA Majority/Minority.
  - Variance Reduction analysis from zones and external points CSV; per-zone statistics and boxplots (PNG).
 
 Requirements:
  - Python packages pandas, scikit-learn and scipy are downloaded automatically on first run (no manual install needed).
  - QGIS "Processing SAGA NextGen Provider" enabled (for the Mode Filter).
